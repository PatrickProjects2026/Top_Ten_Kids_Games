Since you're building a tank game, I’ve tailored this Python 101 tutorial to use game-related examples. This will help you understand the "why" behind the code you’ve been writing.

---

## 1. Variables (The "Storage Boxes")

Variables store information. Think of them as labels for data.

```python
player_name = "TankCommander"  # String (text)
lives = 3                      # Integer (whole number)
speed = 4.5                    # Float (decimal)
is_alive = True                # Boolean (True/False)

```

## 2. Data Types

Python automatically knows what kind of data you are using, but you need to know the big four:

* int: `10`, `-5` (Whole numbers)
* float: `10.5`, `3.14` (Decimals)
* str: `"Hello"` (Text in quotes)
* bool: `True` or `False` (Logic)

## 3. Basic Math

You use math to move your tank and calculate scores.

```python
score = 100 + 50   # Addition
lives = lives - 1  # Subtraction
double_speed = 4 * 2  # Multiplication
half_size = 40 / 2    # Division

```

## 4. Lists (The "Inventory")

Lists hold multiple items in one variable. They start at index 0.

```python
enemies = ["Stalker", "Hunter", "Sniper"]
print(enemies[0])  # Prints "Stalker"
enemies.append("Boss") # Adds to the end

```

## 5. If/Else Statements (The "Brain")

This is how your game makes decisions.

```python
if score >= 1000:
    print("You Win!")
elif score > 500:
    print("Almost there!")
else:
    print("Keep shooting!")

```

## 6. For Loops (The "Repeater")

Use loops to do the same thing to many items (like drawing every wall in your map).

```python
for enemy in enemies:
    print(f"Spawning {enemy}...")

```

## 7. While Loops (The "Game Loop")

A `while` loop runs as long as a condition is true. This keeps your game window open.

```python
running = True
while running:
    # Check for keys, update positions, draw screen
    if lives <= 0:
        running = False # This ends the loop/game

```

## 8. Functions (The "Commands")

Functions are blocks of code you can reuse so you don't have to type the same thing 100 times.

```python
def shoot_bullet(x, y):
    print(f"Bullet fired from {x}, {y}")

shoot_bullet(100, 200) # Calling the function

```

## 9. Classes & Objects (The "Blueprints")

In your tank game, the `Enemy` class is a blueprint. Every time you call `Enemy()`, you create an object from that blueprint.

```python
class Tank:
    def __init__(self, color):
        self.color = color

my_tank = Tank("Green")

```

## 10. Libraries/Imports (The "Power-ups")

Python doesn't come with game tools built-in. You "import" them from libraries like `pygame` or `random`.

```python
import random
print(random.randint(1, 10)) # Gives a random number

```
